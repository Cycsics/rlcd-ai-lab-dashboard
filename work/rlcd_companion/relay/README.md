# 跨网屏幕中继

适用于屏幕和采集电脑不在同一网络、屏幕所在网络没有常驻电脑的场景：

`采集电脑上的看板 → HTTPS 上传 → 常驻服务器 → HTTPS → ESP32`

默认部署仍是本机监控。本目录是可选组件，不会自动上传任何数据。

## 中继服务器

使用 Python 3.6 或以上版本；新部署建议使用仍受支持的 Python 版本。运行 `python frame_relay.py /private/relay.json`。配置示例：

```json
{
  "host": "0.0.0.0",
  "port": 443,
  "read_token": "替换为独立随机读取令牌，至少32个字符",
  "write_token": "替换为另一个随机写入令牌，至少32个字符",
  "certificate": "/private/server.crt",
  "key": "/private/server.key"
}
```

证书必须包含实际连接域名或 IP 的 SAN；可使用受信 CA 或专用私有 CA。配置和私钥仅允许服务账户读取。通过服务管理器设置开机启动及失败重启，并在云安全组开放实际使用的 HTTPS 端口。不要把看板的 8787 配置端口暴露到公网。

中继只保存一张内存画面，超过 30 秒未上传返回 503；重启后必须等待新画面。读取和上传使用不同 Bearer 令牌，仅提供 `/frame.bin` 和 `/upload`，不转发配置页面或账户密钥。温湿度、电量和 USB 状态经校验后回传，30 秒后失效。不记录请求地址、鉴权信息或画面内容。

## 采集电脑

保持本机看板运行，将配置保存在版本库外：

```json
{
  "url": "https://screen.example.com/upload",
  "token": "上面的写入令牌",
  "ca": "ca.crt"
}
```

将信任的 CA 文件放在配置旁，执行 `python publish_frames.py /private/publisher.json`。程序每约 3 秒读取本机 8787 端口的画面并上传；使用直接网络连接，不继承系统代理。`publisher-status.json` 只记录同步成功与否、时间及异常类型。

Windows 可用任务计划程序在当前用户登录时启动 `supervise.py /private/supervisor.json`。该配置的 `jobs` 是名称、命令数组、工作目录和可选环境变量的列表；守护程序每 3 秒检查退出的子进程并重启。使用当前登录用户以读取该用户的 AI 客户端状态；不要改用 SYSTEM 账户。停止时，在配置旁创建 `stop-supervisor` 文件；再次启动前删除该文件。

若保留独立采集器，设置看板环境变量 `RLCD_LOCAL_ENABLED=0` 避免重复采集；保留原 Hooks 安装路径，将其上报地址改为 `http://127.0.0.1:8787`，并使用本机看板的上报令牌。修改前备份配置及数据库。

## 屏幕

在私有 `config.h` 中设置 HTTPS `FRAME_URL`、读取令牌 `FRAME_BEARER_TOKEN` 和 PEM 格式 `FRAME_CA_CERT`，重新编译刷入。固件先同步网络时间，再验证服务器证书；不会忽略证书错误。公网不可达时保留最后画面，并在连续失败 30 秒后标记连接中断。

如需电脑关机后继续显示，在看板设置中关闭 USB 断开自动待机，并为屏幕提供独立电源或使用板载电池。板上电源键的开关机方式以硬件说明书为准。

部署验收：检查无令牌返回 401、正确读取返回恰好 15,000 字节、停止上传 30 秒后返回 503、重新上传后恢复；然后在屏幕端确认 Wi-Fi、HTTPS、温湿度回传和断网提示。
